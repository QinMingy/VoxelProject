# 月面采掘

**全局美术方向**：[美术规范 v1](docs/art/ART_BIBLE.md)统一角色、体素环境、道具、UI、特效和宣传素材。后续资源批次先读取该规范与[规格锁定表](docs/art/style-lock.json)，使用[24 色调色板](docs/art/palette-v1.gpl)。目标为「2D 像素精灵 + 3D 体素布景」；当前原型资源尚未全部迁移，不能把文档完成视为画面换装完成。玩法、界面与镜头的实现变更记录在[实现变更记录](docs/implementation-log.md)。

**展览馆大厅**：开始页进入后，直接来到唯一的 3D 体素展馆。普通地面上以细橙线划分 A/B/C/D 四个展区，每个展区六列两排统一小展台；读取当前存档的真实陈列，新档为空馆；共 48 个展台，容量按展区扩建为 6 → 12 → 24 → 36 → 48。大厅没有可操控主角，点击已开放展台在原场景打开仓库：左侧是藏品列表（已陈列的藏品带「展出中」标签），右侧是藏品信息与唯一的操作按钮（空台安装、已陈列拆卸、被占用替换，三者互斥），标题两侧的左右箭头可切换上一个/下一个展台；选中展台（点击或箭头）会取消列表选中并显示该展台当前陈列，可直接拆卸，只有点选列表藏品才进入安装/替换准备；选中展台会把镜头平滑聚焦过去，总览可用鼠标滚轮缩放。点击待扩建展台查看展馆研究。仓库、布展与大厅共用同一个世界、相机和三名观众，打开/关闭面板不切换视角、不重建展厅，观众继续参观。在展品前停留时，约每 7–11 秒出现一条评价，持续约 4 秒，同一时刻最多一个气泡。评价读取实际展品与等级；空馆只表达期待，换展立即撤掉旧评价。右下角「装备／仓库／出发」接入原有技能树、仓库和选矿区流程，出发按钮本身不扣费。离开展厅后停止绘制、参观和评论计时。布局参考保存在 [展厅概念图](docs/art/museum-lobby-reference.png)。

大厅检查：`Godot --headless --path <项目目录> --script res://tests/museum_lobby_smoke.gd`。去掉 `--headless` 会保存三档尺寸的空馆／满馆运行截图到 `.build/museum-lobby-preview/`；检查使用内存存档，不改玩家进度。
结算面板检查：`Godot --headless --path <项目目录> --script res://tests/settlement_smoke.gd`；去掉 `--headless` 会把安全返航与紧急失事两种结算截图存到 `.build/museum-ui-preview/`。

观众检查：`Godot --headless --path <项目目录> --script res://tests/museum_visitors_smoke.gd`，覆盖参观避障、不同展品及等级评价、周期单气泡、隐藏暂停和换展失效。

正常游戏双击 `Play.cmd`，或在 Godot 中按 F5：**开始页 → 展览馆大厅 → 装备／选择矿区 → 远征 → 展览馆大厅**。安全返航后回到大厅并自动弹出结算面板；点击「仓库」查看已拥有藏品与展台，选中展台会把镜头平滑聚焦到该展台，布展区域与大厅共用同一套展馆场景。技能树分为“远征装备”和“博物馆研究”两页，共十条路线、28 个节点。选中查看详情，确认升级才扣钱或研究点。同路线逐阶解锁，带入场、焦点与购买脉冲／连线点亮动效；小屏可滚动。选关只在点击「出发」时扣一次门票，正常流程已删除“24 秒试玩”按钮和 T 快捷入口。大厅及各菜单暂停世界，返回子页面仍留在大厅。

新增 **勘探范围**：可开采区域半径按 **14 → 18 → 22 → 26 米**成长，直径为 **28 → 36 → 44 → 52 米**，最大就是此前的活动范围。三次升级暂定花费 **140／360／800**。矿点数量按面积比例增加，免费矿区为 **21 → 35 → 52 → 72 个**；碎晶洼地 **26 → 43 → 64 → 90 个**，深埋矿脉 **14 → 23 → 34 → 48 个**。价格、矿物尺寸和氧气上限不随范围自动变化。升级只影响下一趟，选关页显示下一趟半径和矿点数量。旧 v1/v2 成长存档保留资金、原有装备与记录，新范围等级补为 0，正常保存为 v3。

**冒险遗物调试**：`Play-Adventure.cmd` 保留为独立调试启动器，直接试玩舱前宝箱、盾牌和战锤，24 秒氧气，临时进度，不读写原有成长和图鉴。大厅右上角 GM 可进入「舱内测试」；该 GM 入口免门票，但带回后的收益与图鉴使用当前进度。正常矿区的遗物数量随区域面积增加，免费／碎晶／深埋区的目标占比分别为 20%／18%／33%，取整并保留宝箱、盾牌、战锤各一件的底线；遗物数量超过三件时，魔法书和大箱子按轮换出现。

**馆藏经验**：安全带回的物品直接归档为对应类别。同类只保留一件，每次再获得同类物品就给该物品累积经验；每个等级需要依次再获得 2／3／4／…／10 件，升满共 55 件。馆内展示真实体素模型，四个展区共 48 个展台，初始开放 6 个，可扩建到 12／24／36／48 个。八类藏品是小／中／大晶石、宝箱、盾牌、战锤、魔法书和大箱子；已拥有的藏品可以调整展台，未陈列的仍在同一列表里。不再有磨损、鉴定或出售。

首件获得即为 Lv.1；升级不消耗藏品，只让展示效果与收益提高。每次首次发现获得 1 研究点，每次升级再获得 1 点，六类升满共 60 点。满级后继续获得的同类物品只累加件数，不再升级。仓库页只显示已拥有物品的等级、经验、当前展台与收益。

展台扩建花费现金 600／1800／3600／6000；展馆吸引力花费研究点 10／20／30，倍率为 1／1.35／1.75／2.25。八类藏品各升满十级共获得 80 点，覆盖全部吸引力升级（60 点）后仍余 20 点。每件已展示藏品的标准收益为 round(基础价值 × 6% × (1 + 0.15 × (等级 − 1)) × 吸引力倍率)，只计算有效展台上的藏品。出发时记录标准收益，安全返航时按有效出舱时长结算：满 10 秒起，实际收益为 floor(标准收益 × min(时长 / 65, 1))，65 秒达到单趟上限。菜单、GM、失焦和离线不累计；中途新增展品或购买升级只影响下一趟。救援不支付展览收入。公式和经济账已用真实后端验算，实际采集节奏仍待试玩；详见 [数值说明](docs/BALANCE.md)。

藏品件数与等级、研究点、现金、科技和远征编号共同保存在 v7 `progression.cfg`。结算与布展采用先写盘后更新状态的事务，重复结算不会重复归档或收入。回舱写盘失败时，物品仍留在现场背包中并打开暂停提示，可在恢复保存后关闭背包重试。旧 v1–v5 存档在读取时备份为 `progression.cfg.v<版本>.bak`，然后按全新档开始；v6 存档备份为 `.v6.bak` 后迁移到 48 槽并保留藏品与容量档位。首次读取不改写旧文件。

四种源模型（宝箱、盾牌、战锤、魔法书）采用 Kay Lousberg 的真实免费 CC0 源资产，来源及许可见 [素材说明](assets/adventure/README.md)；大箱子复用宝箱模型等比放大到 1.5 米后体素化。它们保存为低模源模型，先按正面姿态转换成与土共用的 **0.125 米格子**并缓存，埋藏时各轴只允许 **0°／90°／180°／270°**。转向直接重排已有格子与面颜色，不再按斜角重新采样，因此各姿态的格数、轮廓结构和表面面积保持一致。逐格替换土层，按最终边界面计算暴露率，取走后留下相同形状的空腔。背包旋转、丢弃和估价继续有效。售价和背包大小不随埋藏角度改变。物品仍为静态，未加刚体。

当前是粗粒度的造型验证：细小锁扣、薄边等会变厚或丢失；完全封闭的内部空腔按整件收集物填实。桌面已验证生成和实际挖掘，手机耗时尚未真机测量。

试玩安装包见 [GitHub Releases](https://github.com/QinMingy/VoxelProject/releases)。源码仓库是独立 Godot 项目：克隆后，用 **Godot 4.7.2** 打开仓库根目录的 `project.godot`，按 F5 运行项目，或打开 `main.tscn` 后按 F6 运行当前场景。无需上层 TapTap Maker 工程。

导出产物统一放在 `exports/release/`：

- Windows：`MoonExcavation-Windows-x64.zip`，解压后运行 `MoonExcavation.exe`，无需安装 Godot；若包内附带 `.pck` 或其他运行文件，请一起保留。
- Android：`MoonExcavation-Android.apk`，安装后默认横屏并启用触控。当前为本地调试签名试玩包，包含 ARM64 和 ARMv7，最低 Android 7.0；不是商店发布包。
- `SHA256SUMS.txt`：导出文件的校验值。

两端使用同一套玩法和存档规则，但各自保存进度，不会自动同步。

**一键发版：双击 Godot 项目根目录的 [Publish.cmd](Publish.cmd)。** 需要已安装 Git、已配置提交身份，并能通过 Git 向 `origin` 推送；无需本机安装导出工具链。脚本显示变更，自动提交当前项目全部非忽略改动，创建版本标签，并将当前分支和标签一起原子推送；随后由现有 GitHub Actions 打包 Windows／Android 并发布。窗口在结束时保留，便于查看进度链接或错误。

默认读取本地及实际推送目标的版本，取最高 `主.次.补丁` 的补丁号加一，固定加 `-demo` 后缀（预发布）；例如 `v0.1.1-demo` → `v0.1.2-demo`。无标签时从 `v0.1.0-demo` 开始。工作区无改动时直接为当前提交发版；有改动时使用默认提交说明 `chore: release <版本>`。已有 Git 忽略规则会排除开发存档、缓存、导出包与本机签名文件；已经被 Git 跟踪的文件仍按正常变更提交。

远端领先/分叉、未处理的合并、重复版本等会停止发布，不自动合并或覆盖标签。推送中断时，提交、标签与 Git 目录内的 `publish-demo-pending.json` 保留；排除问题后再次双击会重试同一版本。重试前不要继续修改工作区或切换分支。若远端已接受上次推送，会核对后清除待推送记录；若 Actions 本身失败，在对应运行页重跑该次工作流。

可选命令（在 Godot 项目根目录的 PowerShell 中运行）：

```powershell
# 只显示变更和下一版本，不暂存、提交、创建标签或推送；不下载分支历史
.\Publish.cmd -DryRun
# 指定版本与提交说明；不带 -demo 为正式版，版本必须未使用
.\Publish.cmd -Version v0.1.2-demo -Message "更新展馆与观众"
```

脚本主体为 [tools/publish_demo.ps1](tools/publish_demo.ps1)，从脚本自身路径确定项目根目录。`Publish.cmd` 仅为此次 PowerShell 进程放行本地脚本执行，不更改系统执行策略。自动发版工作流位于 `.github/workflows/release.yml`。也可以手工提交并推送修改，再创建新版本标签：

```sh
git tag v0.1.2-demo
git push origin v0.1.2-demo
```

GitHub Actions 会下载并校验固定版本的 Godot 4.7.2 和模板，运行体素、背包、养成、雷达、触控和音效检查，然后导出 Windows ZIP、Android APK。两个包通过 CRC、Android 签名、版本与内容检查后，才会创建并公开对应 Release，附带 `SHA256SUMS.txt` 和 `build-info.json`。构建失败不会公开新 Release；可到 [Actions](https://github.com/QinMingy/VoxelProject/actions/workflows/release.yml) 查看日志并重跑失败任务。

标签格式为 `v主版本.次版本.修订号`，可附加 `-demo`、`-beta.1` 等后缀；带后缀会标为预发布。Android 版本名取标签去掉开头的 `v`，版本代码取该工作流运行编号加一（原始手动包为 1）；重跑同一次任务保持版本代码。保持此工作流文件与编号连续，并按发布顺序使用递增版本。已公开的相同标签附件不会被自动覆盖。

APK 沿用首次试玩包的调试签名，密钥保存在仓库 Actions Secret `ANDROID_DEBUG_KEYSTORE_BASE64`，仅在构建临时还原并清理。新建仓库或复制工程时，需要在 Settings → Secrets and variables → Actions 配置同名 Secret，内容为同一份调试 keystore 的 Base64；不要把密钥提交进源码。当前自动产物仍是调试签名试玩 APK，尚未完成 Android 真机验证。

不发版只验证打包时，可在 Actions → Build and Release → Run workflow 手动运行；包和日志保存在对应运行页的 Artifacts。手动运行不会公开 Release。标签必须指向含有此工作流的提交；旧标签不会自动补跑。

自行导出需要安装与引擎版本一致的 **Godot 4.7.2 导出模板**。Android 另需 **JDK 17、Android SDK（含平台工具与构建工具）和本机调试 keystore**；这些工具、模板与签名文件均不随源码提交。仅在 Godot 编辑器中试玩不需要 Android 工具链。

当前导出预设的自定义模板与调试签名路径沿用 `.build/tools/` 本地打包目录。若通过 Godot 导出界面手动构建，请清空各预设的 `custom_template/debug` 和 `custom_template/release`，使用已安装的对应版本模板；在编辑器设置中配置自己的 JDK／Android SDK，并将 Android 调试 keystore、别名和密码配置为本机值。`tools/package_demo.ps1` 按脚本中的 `.build/tools/` 目录约定查找依赖，不会自动下载；运行时通过 `-GodotPath` 指定自己的 Godot 可执行文件。签名文件与个人配置应留在本机。

界面采用大字号与紧凑信息卡：局内左侧显示氧气、返程、背包占用与累计补氧，探测仪可在顶部方位条和右上圆形盘之间切换；局内不再显示目标物品信息卡（暴露与估价在背包/仓库查看）。所有菜单列表支持单指上下拖动滚动。触控 HUD 中拾取与交互只在可用时出现、基地按钮仅在舱内显示；跳跃为更大的圆形按钮；左上角齿轮进入按键布局编辑，可拖动位置、缩放选中按键并保存到存档，支持恢复默认与取消。常驻操作提示默认隐藏，H 展开／收起完整按键帮助；释放鼠标时仍显示「点击画面继续」。大厅、选关、技能树和收获记录各有独立页面；收获记录可滚动查看完整明细，背包格内显示矿石轮廓与估价，点选后查看详细信息。

V 在原来的过肩第三人称与第一人称之间切换。同一角色、挖掘射线和氧气进度保持，切换取消未完成的挖掘蓄力；菜单内不会切换。第一人称隐藏全身模型，使用右下角电镐和手套，镜头置于角色头部、工具局部震动，不附加镜头晃动。两种模式都可以移动、跳跃、挖掘和收集晶石。

初始正常出舱有 65 秒氧气，升级后最高 95 秒；一趟内仍有固定上限。24 秒试炼只保留在 GM 调试中。界面提示登月舱方向和直返所需时间。鼠标点击重新捕获、窗口重新获得焦点时居中，并忽略重定位产生的瞬间位移，避免镜头跳转。Esc 仍可释放鼠标。

跳跃初速度为 5.2 米/秒、重力为 12 米/秒²，平地起跳约 1.1 米；空中仍可用 WASD 调整位置，没有二段跳或按住连跳。小于等于 0.25 米的低台阶可直接走上，更高的坑沿需要跳跃。人物用实际体素占格检查头顶、侧面和脚下，挖掉脚下土会下落；土与晶石都可承托和阻挡。打开背包、GM 或基地暂停跳跃，返回舱边时清除速度。

**GM 面板**：大厅右上角「GM」或 G 打开，分为「采掘调试」和「科技调试」。科技页可直接设置十项科技的等级（包括降级）、全部归零／满级、增加 1000／10000 资金或 10 研究点。设置等级不扣费，立即保存并同步装备、技能树与展台容量；归零保留资源和藏品，容量降低时超出的展品只从展台撤下，藏品本身保留。仅在舱内且远征已结算、现场背包为空时允许科技调整。

采掘页集中提供触控模式、音效开关、两种雷达样式、三种笔刷、补满本趟氧气、返回舱边（不结算）、电镐提速／恢复、性能统计，以及舱内的新矿区／24 秒试炼／图鉴重置按钮。打开时暂停世界和氧气，G、Esc 或关闭按钮返回；鼠标键盘模式恢复打开前的捕获状态。GM 与背包、基地互斥。采掘调试设置重开程序恢复默认；科技等级和资源修改保留在当前存档。

音效包含电镐持续运转和碎土、脚步与跳跃落地、晶石露出／松动／拾取／丢弃、氧矿吸收、低氧和边界警报、探测提示、出发／安全撤离／救援，以及菜单、旋转、购买和错误反馈。音效由项目内脚本合成，不依赖外部音源；密集事件有限频与同时播放上限。打开菜单停止开采和脚步循环，界面操作仍有反馈；GM「音效」可关闭全部音效。本版没有背景音乐。

**小孤立土块清理默认启用，阈值为 9 格**，可在 GM 调整为 1–64 格或关闭。阈值指整块通过六个面相连的土格总数；完整孤岛不超过阈值才删除，连着大地的细桥、大于阈值的孤岛、基岩和世界边界不删。晶石永不删除；与晶石接触的土暂时保留，整颗晶石取走后再检查。被清掉土块中的氧矿直接恢复氧气并显示补充秒数，不额外生成成百粒特效。

自动检查由挖掘和取走晶石触发，只排周围候选格；跨区块按同一网格查连接。每帧共享最多 1024 次格子查询，另有 1.5ms 软时间预算，单个小块必须完整检查后才删除，原子检查与收尾可能略超软时间。地形更新仍合并到受影响区块。GM「清理玩家附近」在关闭面板后分帧检查身边 2 米，用于修改阈值后的对比，可能需要数秒；不扫描整张地图。

远景底图为 **64×64 米**，实际活动区为中心半径 **14／18／22／26 米**的圆形，随勘探范围升级；活动圈外只作远景。距本趟活动边界 **6 米**内，附近一段红色警示网逐渐显现，并提示剩余距离；离开边缘后隐去。人物在距红线 0.35 米处停止向外移动。矿物完整体素轮廓、丢弃位置都限制在本趟活动圈内；笔刷和孤立块清理也不会删除圈外的土。

每趟重新生成缓和起伏，基地附近保留安全平地。保持 **0.125 米体素**；远景用简化网格，近处目标 121 个、最多保留 169 个 2 米细节区块，每帧最多构建一个。已挖空的数据单独保存，离开细节范围再返回仍保留挖坑。首次碎矿所需材质在启动阶段预热。远景使用距离雾，距相机 10 米后开始，28 米处融入背景，近处采掘保持清晰。

免费基础矿区在范围满级时每趟生成 **72 个**埋藏点，其中有 **66 颗晶石和 6 件冒险遗物**；初始范围为 21 个埋藏点，全部位于活动区内。晶石分小、中、大三档，高 **0.50 / 0.625 / 0.75 米**，分别由 **22 / 56 / 95 格**组成。晶石与土使用同一个 **0.125 米网格**，大小由格子数量与形状决定，埋藏状态不使用缩放或旋转。同一格只能是土、晶石、空气之一，生成晶石时逐格替换对应的土，周围土格直接贴合晶石轮廓，不能互相穿插。同档晶石共享网格，三档共用 shader，材质仍保留磨损参数但当前固定为 0，远处晶石不绘制。

基地周围保证有近距离矿点，其余分散在圆形矿区，尽量保持至少 2.8 米间距。露头和全埋晶石混合生成，完全埋藏时不显示模型；探测范围内的方向、距离信号辅助找矿，初始范围 10 米，可升级扩大，挖露之后才显示品相和开采提示。电镐只清除土，晶石占格始终保留；角色与相机也把晶石视为实心格。整件取走后，原晶石占格变为空气，留下精确轮廓空腔，不删除旁边的土。

暴露率直接计算晶石边界面中相邻格为空气的比例，不再使用晶石中心与面外偏移点采样。内部两个晶石格之间的面不计，底面计入。达到 **80%** 后，再检查完整晶石格集向上移动 **1、2、3 格（最多 0.375 米）**是否遇到土或另一颗晶石，忽略它自己的原占位；通过后可按 F 整块取出。80% 是试玩阈值，这仍是短距离向上取出的简化规则，不模拟整条搬运路径与侧向拖出。松动时保持模型位置，不通过晃动造成格子错位。

背包初始为 **4×4 格**，可在基地升级为 **5×4、5×5 格**，小、中、大晶石分别占 **1×1 / 1×2 / 2×2**，基础价分别为 **180 / 400 / 760**。可以选中、旋转、换位，不能重叠或越界。背包界面暂停世界和氧气，关闭后恢复；打开前的鼠标捕获状态也会恢复。装不下时会保留地上的目标并自动打开背包，腾出空间后点「尝试装入待收集晶石」。丢弃会在脚边找有承托、可容纳完整晶石的格子位置，保留大小，可再次按 F 拾取；没有安全落点时保留背包物品并提示换位置，不通过删土强行放入。

可在一趟里连续收集多颗。挖松、可拾取的晶石显示青绿色描边：描边由单独的剪影遮罩做屏幕空间膨胀，像素宽度恒定，只画在物体外侧一圈，遮挡仍由真实土层与角色决定，不透墙提示埋藏物。拾取后晶石直接进入格子背包，场景模型隐藏，不再挂在角色背上；丢弃后静态放在脚边并恢复描边。晶石暂不加入刚体、重力或弹跳，仍按共享体素格固定，避免松动时被残土弹开。

青绿色散矿现在是**氧矿**，吸收后每粒恢复 **0.02 秒**氧气，最多补到本趟氧气上限，且单趟累计实际补氧受补给额度 **6／10／16／24 秒**限制。额度随氧矿补给升级提高，新出舱时重置；消耗氧气不会恢复额度。满氧时多出的部分不储存、不消耗额度、不换钱，也不占晶石背包。飞行中的氧矿在到达角色时补氧；已结束本趟后不会继续到账。每格只产出一次，不原地重生；孤立土块清理也使用同一补氧规则。HUD 显示本趟已恢复／总额度。

现金来自已布展藏品的远征结算收益。物品不再出售，带回后直接归档为对应类别。氧气耗尽时，本趟背包里的物品全部遗落，既有藏品与研究点保留。氧矿只作补氧，不直接卖钱。

每次出舱刷新矿床。磨损与品相不再生成或显示：晶石材质保留磨损遮罩，但当前固定为新品外观。背包中的每件物品只显示类型、大小与估价。

售价不再隐藏：物品获得后即可看到估价，估价 = 基础价，不随磨损变化。旧 `catalogue.cfg` 不再写入；F9 或 GM“重置估价图鉴”只清空旧鉴定缓存，不影响资金、科技与藏品。

编辑器版本运行项目时，存档位于项目目录 `.demo-data/`；Windows／Android 导出程序使用可写的 `user://` 应用数据目录，不向安装目录或 APK 写入。导出包不附带开发时的资金、装备和图鉴；首次启动使用初始进度。编辑器试玩档和导出程序的试玩档互相独立，移动导出文件不会把编辑器档带过去。

局外流程为：大厅 → 购买永久升级／查看博物馆 → 选择矿区并支付门票 → 探测、挖掘与装包 → 安全回舱入库 → 展示与研究。带回物品后自动弹出结算面板，空手返回或救援回到大厅；各页面与背包、GM 互斥。初始资金 150，永久升级不占背包、失败不掉级。门票在成功出发时只扣一次，免费矿区始终可选。关闭游戏不会保存未返航货物或退还已经支付的门票。

氧矿密度在**下一次出舱生成矿区**时生效，不改变当前矿床，也不增加单粒补氧量。相同种子下，高等级会保留低等级的氧矿位置并增加新的位置；渲染颜色、手动挖掘和碎土清理使用同一判定。初始密度是旧矿脉候选格的 25%，最高为 85%，不是整张地图 85% 都是氧矿。实测大范围＋快电镐在富矿中能净补氧，因此用累计额度保证常规单趟有效氧气最多 65+6 至 95+24 秒；暂停、GM 和失焦不累计活动时长。

探测仪同时显示范围内所有未收集宝物，氧矿不产生回波。默认是右上角的 **圆形雷达**：中央空心箭头代表玩家，上方是镜头朝向；标记按实际水平距离从圆心向外映射，没有人为的最小离心距离，因此正下方目标可以与玩家箭头重合，箭头轮廓不会完全盖住回波。目标越近，标记越大、越亮；越远越小、越透明。抬头低头不会改变水平方位。探测范围按真实三维距离计算，范围外、已收集物不会显示。

按 **G → 雷达样式 → 方位条／圆形盘** 可随时对比。方位条位于屏幕中央上方，覆盖 360°：中间为正前方，两端为正后方；相近方位的标记分三行排列，不横移伪造方向，极密集时合并数量。切换仅改变显示，不换矿区、不花钱、不重置目标，当前运行内跨趟保留，重新打开默认圆形雷达。基础设备即可显示多目标方位，Lv.1 扩大范围，Lv.2 增加埋深区间，Lv.3 增加体积回波；升级费用与范围保持不变。圆形盘文字摘要对应最近宝物，观察卡仍对应眼前露出的宝物，二者可能不同。价格与世界坐标不会被探测仪揭示。挖掉覆盖土层可改变埋深，不代表探测到了氧矿。
