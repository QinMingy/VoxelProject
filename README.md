# 月面采掘

试玩安装包见 [GitHub Releases](https://github.com/QinMingy/VoxelProject/releases)。源码仓库是独立 Godot 项目：克隆后，用 **Godot 4.7.2** 打开仓库根目录的 `project.godot`，按 F5 运行项目，或打开 `main.tscn` 后按 F6 运行当前场景。无需上层 TapTap Maker 工程。

导出产物统一放在 `exports/release/`：

- Windows：`MoonExcavation-Windows-x64.zip`，解压后运行 `MoonExcavation.exe`，无需安装 Godot；若包内附带 `.pck` 或其他运行文件，请一起保留。
- Android：`MoonExcavation-Android.apk`，安装后默认横屏并启用触控。当前为本地调试签名试玩包，包含 ARM64 和 ARMv7，最低 Android 7.0；不是商店发布包。
- `SHA256SUMS.txt`：导出文件的校验值。

两端使用同一套玩法和存档规则，但各自保存进度，不会自动同步。

自行导出需要安装与引擎版本一致的 **Godot 4.7.2 导出模板**。Android 另需 **JDK 17、Android SDK（含平台工具与构建工具）和本机调试 keystore**；这些工具、模板与签名文件均不随源码提交。仅在 Godot 编辑器中试玩不需要 Android 工具链。

当前导出预设的自定义模板与调试签名路径沿用 `.build/tools/` 本地打包目录。若通过 Godot 导出界面手动构建，请清空各预设的 `custom_template/debug` 和 `custom_template/release`，使用已安装的对应版本模板；在编辑器设置中配置自己的 JDK／Android SDK，并将 Android 调试 keystore、别名和密码配置为本机值。`tools/package_demo.ps1` 按脚本中的 `.build/tools/` 目录约定查找依赖，不会自动下载；运行时通过 `-GodotPath` 指定自己的 Godot 可执行文件。签名文件与个人配置应留在本机。

**触控模式**可在右下角「GM 调试」中开关：Windows 默认鼠标键盘，Android 默认触控。电脑也可以用鼠标模拟单个触点，实际双指操作仍需触屏。

界面采用大字号与紧凑信息卡：局内左侧显示氧气、返程、背包占用与累计补氧，探测仪可在顶部方位条和右上圆形盘之间切换；晶石卡保留暴露、磨损和估价。常驻操作提示默认隐藏，H 展开／收起完整按键帮助；释放鼠标时仍显示「点击画面继续」。基地升级和矿区详情可悬停查看，结算保留收入／门票／净收益摘要，完整明细在悬停提示中；背包格内显示矿石轮廓与估价，点选后查看详细信息。

V 在原来的过肩第三人称与第一人称之间切换。同一角色、挖掘射线和氧气进度保持，切换取消未完成的挖掘蓄力；菜单内不会切换。第一人称隐藏全身模型，使用右下角电镐和手套，镜头置于角色头部、工具局部震动，不附加镜头晃动。两种模式都可以移动、跳跃、挖掘和收集晶石。

初始正常出舱有 65 秒氧气，升级后最高 95 秒；一趟内仍有固定上限。想快速试撤离取舍，可以在舱门旁按 T 用 24 秒氧气出发，镜头会朝向附近的一颗晶石。界面提示登月舱方向和直返所需时间。鼠标点击重新捕获、窗口重新获得焦点时居中，并忽略重定位产生的瞬间位移，避免镜头跳转。Esc 仍可释放鼠标。

跳跃初速度为 5.2 米/秒、重力为 12 米/秒²，平地起跳约 1.1 米；空中仍可用 WASD 调整位置，没有二段跳或按住连跳。小于等于 0.25 米的低台阶可直接走上，更高的坑沿需要跳跃。人物用实际体素占格检查头顶、侧面和脚下，挖掉脚下土会下落；土与晶石都可承托和阻挡。打开背包、GM 或基地暂停跳跃，返回舱边时清除速度。

**GM 面板**集中提供触控模式、音效开关、两种雷达样式、三种笔刷、补满本趟氧气、返回舱边（不结算）、电镐提速／恢复、性能统计，以及舱内的新矿区／24 秒试炼／图鉴重置按钮。打开时暂停世界和氧气，G、Esc 或关闭按钮返回；鼠标键盘模式恢复打开前的捕获状态。GM 与背包、基地互斥。调试设置保留到下一趟，重开程序恢复默认。

音效包含电镐持续运转和碎土、脚步与跳跃落地、晶石露出／松动／拾取／丢弃、氧矿吸收、低氧和边界警报、探测提示、出发／安全撤离／救援，以及菜单、旋转、购买和错误反馈。音效由项目内脚本合成，不依赖外部音源；密集事件有限频与同时播放上限。打开菜单停止开采和脚步循环，界面操作仍有反馈；GM「音效」可关闭全部音效。本版没有背景音乐。

**小孤立土块清理默认启用，阈值为 9 格**，可在 GM 调整为 1–64 格或关闭。阈值指整块通过六个面相连的土格总数；完整孤岛不超过阈值才删除，连着大地的细桥、大于阈值的孤岛、基岩和世界边界不删。晶石永不删除；与晶石接触的土暂时保留，整颗晶石取走后再检查。被清掉土块中的氧矿直接恢复氧气并显示补充秒数，不额外生成成百粒特效。

自动检查由挖掘和取走晶石触发，只排周围候选格；跨区块按同一网格查连接。每帧共享最多 1024 次格子查询，另有 1.5ms 软时间预算，单个小块必须完整检查后才删除，原子检查与收尾可能略超软时间。地形更新仍合并到受影响区块。GM「清理玩家附近」在关闭面板后分帧检查身边 2 米，用于修改阈值后的对比，可能需要数秒；不扫描整张地图。

地图从 256×256 米收缩至 **64×64 米**，实际活动区为中心半径 **26 米**的圆形，外圈只作远景。距活动边界 **6 米**内，附近一段红色警示网逐渐显现，并提示剩余距离；离开边缘后隐去。人物在距红线 0.35 米处停止向外移动，丢弃物也留在圈内。

每趟重新生成缓和起伏，基地附近保留安全平地。保持 **0.125 米体素**；远景用简化网格，近处目标 121 个、最多保留 169 个 2 米细节区块，每帧最多构建一个。已挖空的数据单独保存，离开细节范围再返回仍保留挖坑。首次碎矿所需材质在启动阶段预热。远景使用距离雾，距相机 10 米后开始，28 米处融入背景，近处采掘保持清晰。

免费基础矿区每趟生成 **72 颗**晶石，全部位于活动区内，分小、中、大三档，高 **0.50 / 0.625 / 0.75 米**，分别由 **22 / 56 / 95 格**组成。晶石与土使用同一个 **0.125 米网格**，大小由格子数量与形状决定，埋藏状态不使用缩放或旋转。同一格只能是土、晶石、空气之一，生成晶石时逐格替换对应的土，周围土格直接贴合晶石轮廓，不能互相穿插。同档晶石共享网格，三档共用 shader，磨损参数每颗独立，远处晶石不绘制。

基地周围保证有近距离矿点，其余分散在圆形矿区，尽量保持至少 2.8 米间距。露头和全埋晶石混合生成，完全埋藏时不显示模型；探测范围内的方向、距离信号辅助找矿，初始范围 10 米，可升级扩大，挖露之后才显示品相和开采提示。电镐只清除土，晶石占格始终保留；角色与相机也把晶石视为实心格。整件取走后，原晶石占格变为空气，留下精确轮廓空腔，不删除旁边的土。

暴露率直接计算晶石边界面中相邻格为空气的比例，不再使用晶石中心与面外偏移点采样。内部两个晶石格之间的面不计，底面计入。达到 **80%** 后，再检查完整晶石格集向上移动 **1、2、3 格（最多 0.375 米）**是否遇到土或另一颗晶石，忽略它自己的原占位；通过后可按 F 整块取出。80% 是试玩阈值，这仍是短距离向上取出的简化规则，不模拟整条搬运路径与侧向拖出。松动时保持模型位置，不通过晃动造成格子错位。

背包初始为 **4×4 格**，可在基地升级为 **5×4、5×5 格**，小、中、大晶石分别占 **1×1 / 1×2 / 2×2**，基础价分别为 **180 / 400 / 760**。可以选中、旋转、换位，不能重叠或越界。背包界面暂停世界和氧气，关闭后恢复；打开前的鼠标捕获状态也会恢复。装不下时会保留地上的目标并自动打开背包，腾出空间后点「尝试装入待收集晶石」。丢弃会在脚边找有承托、可容纳完整晶石的格子位置，保留大小和磨损，可再次按 F 拾取；没有安全落点时保留背包物品并提示换位置，不通过删土强行放入。

可在一趟里连续收集多颗。挖松、可拾取的晶石显示青绿色描边，遮挡仍由真实土层决定，不透墙提示埋藏物。拾取后晶石直接进入格子背包，场景模型隐藏，不再挂在角色背上；丢弃后静态放在脚边并恢复描边。晶石暂不加入刚体、重力或弹跳，仍按共享体素格固定，避免松动时被残土弹开。

青绿色散矿现在是**氧矿**，吸收后每粒恢复 **0.02 秒**氧气，最多补到本趟氧气上限，满氧时多出的部分不储存、不换钱，也不占晶石背包。飞行中的氧矿在到达角色时补氧；已结束本趟后不会继续到账。每格只产出一次，不原地重生；孤立土块清理也使用同一补氧规则。结算记录本趟实际恢复了多少秒。

收入仅来自带回并出售的晶石，仍按每颗独立的大小和磨损计价。氧气耗尽时，背包里的晶石全部遗落，未出售的类型不解锁估价；氧矿改为补给后，救援不再有普通矿物保底收入。

每次出舱刷新矿床并生成晶簇的原生磨损。本版磨损在 0%–65% 之间随机，品相整趟固定，挖掘不会改变它。材质上的斑驳遮罩表现磨损，晶簇外形不变。靠近能看到大致品相，表面暴露达到 25% 后显示准确完好度。背包中的每件物品都显示磨损。

首次遇到大晶簇时，售价为 `？`。第一次安全带回并出售后揭晓基础价，图鉴记住该类型；以后同类检查完即可看到估价。售价 = 基础价 × 完好度，结算卡会展开计算。本版数值仅供测试。图鉴文件为 `catalogue.cfg`，资金、六类装备等级和所选矿区保存在 `progression.cfg`，重新打开仍保留。F9 或 GM「重置估价图鉴」只清图鉴，不清资金和装备。旧版五项装备存档可兼容迁移，保留资金与原等级，新增氧矿密度从零级开始。

编辑器版本运行项目时，存档位于项目目录 `.demo-data/`；Windows／Android 导出程序使用可写的 `user://` 应用数据目录，不向安装目录或 APK 写入。导出包不附带开发时的资金、装备和图鉴；首次启动使用初始进度。编辑器试玩档和导出程序的试玩档互相独立，移动导出文件不会把编辑器档带过去。

局外流程为：基地查看结算 → 购买永久升级 → 选择矿区 → 出发扣门票 → 探测、挖掘与装包 → 回舱出售。启动和回舱自动打开基地，关闭后可用 E / M 再开；界面与背包、GM 互斥。初始资金 150，永久升级不占背包、失败不掉级。门票在成功出发时只扣一次，免费矿区始终可选；24 秒试采使用同样的所选矿区门票。关闭游戏不会保存未返航货物或退还已经支付的门票。

以下升级和门票均为**试玩数值**，尚未验证长期平衡。各条成长共同影响每趟带回的收益，不分主副：

| 永久装备 | 初始 → 后续各级 | 每次升级资金 |
| --- | --- | --- |
| 电镐驱动 | 0.90 → 0.65 → 0.45 → 0.30 秒/次 | 120 / 320 / 800 |
| 氧气罐 | 65 → 75 → 85 → 95 秒 | 160 / 400 / 900 |
| 氧矿密度 | ×1.0 → ×1.6 → ×2.4 → ×3.4 | 180 / 420 / 900 |
| 助力靴 | 3.35 → 3.70 → 4.05 → 4.40 米/秒 | 140 / 360 / 850 |
| 背包扩容 | 4×4 → 5×4 → 5×5 | 220 / 600 |
| 金属探测仪 | 10 → 16 → 22 → 28 米 | 100 / 280 / 650 |

氧矿密度在**下一次出舱生成矿区**时生效，不改变当前矿床，也不增加单粒补氧量。相同种子下，高等级会保留低等级的氧矿位置并增加新的位置；渲染颜色、手动挖掘和碎土清理使用同一判定。初始密度是旧矿脉候选格的 25%，最高为 85%，不是整张地图 85% 都是氧矿。补氧量是原型数值：最高密度和最快电镐下，富矿仍可能短时间净补氧；局内不重生且氧气有上限，长期平衡仍需试玩。

探测仪同时显示范围内所有未收集晶石，氧矿不产生回波。默认是屏幕中央上方的 **360° 方位条**：中间代表镜头正前方，两端代表正后方；方位刻度随水平转向滚动。目标越近，标记越大、越亮；越远越小、越透明。相近方位的标记分三行排列，不横移伪造方向；极密集时用数量标记合并，最近物仍优先可见。抬头低头不会改变水平方位。探测范围按真实三维距离计算，范围外、已收集物不会显示。

按 **G → 雷达样式 → 方位条／圆形盘** 可随时对比。圆形盘位于右上，中心三角代表自己，上方是镜头朝向，同时显示多颗晶石；越近越靠中心，标记同样按距离缩放和变淡。切换仅改变显示，不换矿区、不花钱、不重置目标，当前运行内跨趟保留，重新打开默认方位条。基础设备即可显示多目标方位，Lv.1 扩大范围，Lv.2 增加埋深区间，Lv.3 增加体积回波；升级费用与范围保持不变。圆形盘文字摘要对应最近晶石，观察卡仍对应眼前露出的晶石，二者可能不同。未鉴定价格、磨损及世界坐标不会被探测仪揭示。挖掉覆盖土层可改变埋深，不代表探测到了氧矿。

| 碎晶洼地 | 60 | 90 颗，小件偏多、露头更多，通常覆盖 0.06–0.24 米 |

三者使用当前月面地形生成器，变化已接到物品数量、尺寸权重和埋藏深度；同类晶石价格和磨损规则不因门票直接加成。每图仍保证两个近处露头，便于起步。收高门票不保证回本，背包和开采能力会影响适合的矿区。例如碎晶洼地支付 60，安全带回价值 300 的晶石，收入 300、净收益 240；若氧气耗尽丢失晶石，收入为零、净收益 -60。

结算面板首行显示收入、门票和净收益。存档使用同目录临时文件写完后替换；购买或扣门票保存失败则不扣款。结算写入失败时收入留在当前运行并提示。读取到坏档则保留原文件，转为明显提示的临时试玩，不保存新进度。
