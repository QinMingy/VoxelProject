# 月面原型音效

本目录 WAV 由 `tools/generate_audio.py` 使用 Python 标准库确定性合成，未使用外部录音、样本、音乐或服务。源脚本与生成音频均为本项目原创资源，没有第三方样本的署名或外部许可证依赖。

执行 `python tools/generate_audio.py` 可重新生成。格式统一为 32 kHz、16-bit、单声道 PCM。`drill_loop.wav` 使用完整文件长度循环，其余文件为一次性音效。电镐、碎土和脚步使用机械脉冲、滤波噪声和低频冲击；晶石、补氧、警告和界面使用短包络合成音。多种碎土、脚步及补氧音色轮换，降低连续操作的重复感。

`game_audio.gd` 提供统一触发入口、有限播放池、拾取与警告限频、独立音效混音总线与限幅。默认音量适中。需要替换音色时，保留文件名即可。Godot 的导入压缩由 `.wav.import` 管理，运行时通过资源加载器读取导入文件，支持导出包中的资源重映射。循环长度按采样帧计算，兼容压缩后的 WAV 资源。

运行 `godot --headless --path . --script res://tests/audio_smoke.gd` 可检查 30 个源文件、22 种一次性事件、电镐循环、有限播放池、拾取限频、暂停与失焦停止、静音及动态界面按钮接线。测试会在释放播放器后留出 0.2 秒让音频服务完成混音队列清理。
